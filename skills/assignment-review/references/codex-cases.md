# 独立审阅验收场景

仅用合成材料；这些场景不是课程证据或真实模型审阅。

| 场景 | 实际验证 | 限制 |
|---|---|---|
| preparation 无稿 | 安装目录助手 begin/capture/export，测试适配器的独立进程、终态及来源绑定 | 测试子进程，不是模型推理 |
| in_progress / final / 新当前稿 recheck | 同一完整流程，阶段与当前身份保持，导出哈希一致 | 不证明语义建议质量 |
| 伪造引用、错误 UTF-8 区间、排除/未读材料 | 本地绑定拒绝成功，保留覆盖限制 | 精确引文不证明语义蕴含 |
| 并发运行、崩溃、取消和超时 | 原子 owner、一次派发、脏事务不回退、进程组回收确认 | 不承诺远端请求撤回 |
| 排除组的普通/硬链接/符号链接别名 | 已知 documentId 关联在任何正文读取前被排除 | 不声称自动发现未知物理别名 |
| 文件、认证与工具边界 | 实际 Codex 0.141.0 + Seatbelt + 假认证 + 本地服务；四个内置及未声明外部工具强制调用失败 | 与实际 ChatGPT 推理分别验收 |
| 原始输出、推理与清理 | 已完成记录无原始推理/诊断，只删除同任务已验证记录，外国链接保留 | 崩溃遗留临时目录需明确检查 |

重跑：`node --test tests/codex/*.mjs tests/prompts/*.mjs tests/commands/*.mjs tests/baseline/source-boundary.mjs`（仓库开发者测试，120 秒上限）。实际 CLI 版本/哈希变化会使验收失败，不自动放宽。共享 Skill 的正常安装调用无需仓库测试环境。
