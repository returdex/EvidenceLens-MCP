# EvidenceLens MCP v0.2.4

Prepared release notes; publication is pending. Completes planning milestone v1.1 (Phases 12–17). The milestone marker v1.1 is not the product version.

## Added

- One repository `assignment-review` Skill for adapting prompts and performing explicitly requested preparation, in-progress and final reviews.
- Source-backed task baselines, incremental clarification handling, current-artifact identity and pre-read document-group exclusions.
- Template comparison/restoration handoffs, contextual draft-residue review and evidence-backed centralized AI-use disclosure checks.
- Current-version finding transitions with resolved-action retirement, source-backed recurrence and bounded final conclusions.

## Validation and maintenance

- Official Skill validator and negative control passed with isolated pinned PyYAML 6.0.3.
- Fresh source-bound TypeScript build and provider-disabled default suite: 43 files / 795 tests passed in Phase 16; separate 12-test boundary suite.
- Phase 17 reran 57 synthetic collection steps and 12 boundary tests, completed four task-mapped records and audited 22 requirements.
- Archival-compatible legacy proof rehearsal preserves the real parent requirements state whether the active file exists or has been archived. Final closeout results are recorded in the milestone completion record.

## Scope and known limits

Language judgments are inline/manual synthetic evaluations; independent model robustness, global Skill discovery, automatic Codex invocation, real document editing/signing and remote assignment submission are not established. Existing MCP role/schema/runtime behavior is retained. Historical paid-provider, Linux and Docker proof remains tied to its original certified source; no new paid proof is claimed. Manual coverage and inherited v1.0 debt remain explicitly recorded.
