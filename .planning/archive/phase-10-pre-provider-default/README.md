# Phase 10 historical plan archive

This directory preserves the byte-exact Phase 10 plan and summary history through Plan 10-161.

The files were moved out of `.planning/phases/` on 2026-09-22 so routine GSD discovery and planning load only the active provider-default recovery chain (`10-162` through `10-166`). Moving a file here does not make its historical evidence authoritative and does not permit replay of a consumed provider generation.

Runtime proof artifacts that are still referenced by audit code remain in the active Phase 10 directory. Git history remains the durable source for every archived file and its former path.
