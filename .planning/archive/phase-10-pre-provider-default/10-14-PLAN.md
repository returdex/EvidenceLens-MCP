The existing client contract is:
```javascript
export class StdioClient {
  constructor(child, toolsCallTimeoutMs = controlTimeoutMs)
  next(timeoutMs)
  async request(id, method, params = {})
}
export function methodTimeoutMs(method, toolsCallTimeoutMs = controlTimeoutMs)
```

The initialize request currently advertises protocol version `2025-11-25`. A valid initialize result must be an ordinary object with the negotiated `protocolVersion` string, an ordinary-object `capabilities`, and an ordinary-object `serverInfo` containing non-empty string `name` and `version`. The client notification must be exactly a JSON-RPC 2.0 notification with method `notifications/initialized`, object params, and no `id`.
