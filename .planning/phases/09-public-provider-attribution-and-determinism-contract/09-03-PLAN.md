## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Provider return object → runtime schema/orchestrator | Hostile getters, Proxies, and property access can throw while trusted code validates untrusted provider output. |
| Provider/analyzer exception → public MCP error | Exception source determines whether the caller sees PROVIDER_FAILURE, INTERNAL_ERROR, INVALID_REQUEST, or LIMIT_EXCEEDED; wrong attribution can mislead remediation and leak internals. |
| Provider PDF citation → retained normalized page payload | Provider-controlled visual flags, page numbers, and hashes must not claim visual evidence that was not retained locally. |
| Documentation example → client implementation | Clients may treat the normative JSON example as an exact machine-readable contract. |
