## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local/Docker environment → server startup | Untrusted/missing configuration controls whether a real provider may be initialized. |
| server options → provider registration | Tests and embedders may supply a typed trusted seam; ambient settings must not override it. |
| startup error → stdio/log output | Configuration failures must not disclose key, endpoint, path, cause, or stack. |

| T-10-02 | Information Disclosure | startup/configuration error path | mitigate | Preserve fresh sanitized `PROVIDER_CONFIGURATION`; do not log/copy raw config, key, endpoint, path, cause, or stack. | Negative payload/log assertions for hostile config fixtures. |
