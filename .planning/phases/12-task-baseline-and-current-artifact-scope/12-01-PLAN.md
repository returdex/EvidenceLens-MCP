Export selectBaselineSources(input) and async collectBaselineSources(input, readSource). The sole metadata input is:
{ sources: [{ id, documentId, kind, access, exclusion }], currentSourceId, reviewMode }.
Require all fields and reject unknown keys. IDs/document IDs match ^[A-Za-z][A-Za-z0-9_-]{0,63}$; IDs are unique; sources has at most 100 entries. kind is requirements|rubric|teacher_guidance|template|solution|support|history; access is allowed|excluded|unknown; exclusion is none|whole|partial; currentSourceId is a valid ID or null; reviewMode is artifact_only|process. No raw content, filename, path, URL, policy text or policy-permission flag belongs in this input. documentId is the trusted host's shared identity for known aliases of one underlying document; it is not an automatically verified file identity.

Return:
{ reads: [{id,purpose}], skipped: [{id,reason}], currentArtifact: {sourceId,status} }.
purpose is baseline|current_artifact|process_context. status is selected|not_provided|needs_selection|unavailable. Maintain source order within reads/skipped. Unknown current ID or a designated non-solution yields unavailable and never falls back to another solution; baseline sources remain selectable. Null currentSourceId yields not_provided if no solutions exist, otherwise needs_selection. Do not choose the largest filename version or newest timestamp.

Evaluate document-wide exclusions before target/history rules. If any alias has access=excluded or exclusion=whole, skip that document group with user_excluded; next precedence is any partial exclusion -> partial_exclusion_unsupported; next is any unknown access -> access_unknown. This host-neutral phase deliberately skips the whole document for unsupported partial exclusions; it does not parse or redact PDFs/DOCX. Admitted requirements/rubric/teacher_guidance/template/support have purpose baseline. Only the designated admitted solution has purpose current_artifact. Other solution items are skipped as not_current_artifact, or awaiting_current_selection when no target is designated. History is admitted as process_context only in process mode; otherwise skipped as history_not_requested. Reading historical context never makes it grading evidence.

collectBaselineSources validates/selects first, snapshots the selected IDs, then invokes the trusted injected readSource(id) only for reads, once per admitted ID, in order. It returns {selection,items,unavailable}; items contain {id,content,contentHash}, with SHA-256 of the admitted UTF-8 text only. Accept only strings up to 1,000,000 UTF-8 bytes each, at most 5,000,000 total returned bytes. Stop further reader calls once the aggregate budget is exhausted, marking remaining reads budget_exhausted; an over-budget item is not returned. Callback failures produce read_failed; non-text/oversized content produces unsupported_content. Never propagate callback messages, excluded bodies or paths through errors. Continue other admitted work after an individual unreadable source. This is an injected-reader boundary, not a replacement for host filesystem permissions or source-identity validation. The trusted adapter must bound its own I/O; returned-string checks cannot retroactively bound the callback's file read. selected denotes selection only: a callback failure must leave the actual artifact unread/unverified in the baseline.

The CLI reads at most 32 KiB JSON metadata from stdin and writes selection JSON only; it never collects source content, opens a supplied path, contacts a provider or logs raw input. Malformed/oversized/invalid input exits nonzero with BASELINE_INPUT_INVALID only; success exits zero. Importing the module must not start the CLI. Use Node stdlib only.

Create direct node:test checks that observe actual callback IDs: whole and partial exclusion; known alias exclusion; unknown access; selected current and skipped old solution; missing/unavailable current with continued baseline reads; explicit process history; duplicate IDs/unknown keys; invalid input causes zero reads; callback errors do not leak their sentinel text; per-item and aggregate budgets; changed allowed text yields changed hash without changing the source ID; inputs mutated during callback cannot add selected IDs. Spawn the CLI with synthetic JSON to prove valid selection, invalid input and size bounds. Assert excluded generated sentinel bodies never reach returned items or CLI/error output. Use in-memory synthetic reader data, no private files, no dependencies, no network.
