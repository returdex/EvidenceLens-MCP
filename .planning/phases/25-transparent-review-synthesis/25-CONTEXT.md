# Phase25 approved scope

User continuation authorizes next roadmap phase and local implementation. Preserve all original findings including Low/info, full reports, disagreements and uncertainty. Independent first reviews receive identical authorized task/materials, no peer answer or tutor feedback. Host synthesis is explicitly a judgment, not semantic certification or voting.

D25-01: Default full delivery; explicit brief retains same-run full record.
D25-02: Every original finding appears exactly once in the synthesis ledger, with run/finding/source attribution; common/unique/disagreement/unresolved categories are host judgments, never silently inferred.
D25-03: Every retained/merged/rejected/deferred/closed/reopened decision includes rationale. Closing/reopening requires existing validated current-evidence assessment; one failed reviewer stays visible and does not establish unilateral novelty.
D25-04: No additional model calls, retries, coursework/feedback reads, release or push. Phase26 owns settings defaults; Phase27 owns real semantic acceptance.
