<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| MCP caller -> review handler | Untrusted request enters public schema and role/duplicate gates. |
| authorized evidence -> provider DTO/DeepSeek | Sensitive bounded evidence crosses to selected provider. |
| config/startup -> provider registry | Local settings select endpoint/model/credentials. |
| DeepSeek/fake provider -> MCP response | Provider results and errors cross into public output. |
| runtime registry -> MCP contract | Provider wiring must not change tool schema or enable arbitrary loading. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-05-14 | Information Disclosure | `src/server.ts`, `src/tools/review.ts` | mitigate | Read typed config only, never echo credentials/config, pass bounded DTOs, clear transient payloads in `finally`, and test redaction. |
| T-05-15 | Tampering | `src/tools/review.ts`, response schema | mitigate | Validate provider findings/provenance, keep result sets separate, and reject invalid output without fallback. |
| T-05-16 | Denial of Service / SSRF | `src/server.ts` registration | mitigate | Use endpoint validation and timeout/retry/total-wait controls; fixed DeepSeek path and no arbitrary loading. |
| T-05-17 | Repudiation | provider metadata/result envelope | mitigate | Preserve provider/model/promptVersion/inputFingerprint/requestId and assert attribution. |
| T-05-18 | Information Disclosure | `src/errors.ts` MCP boundary | mitigate | Map provider failures to stable generic code/message and test absence of secrets, paths, URLs, bodies, and stacks. |
| T-05-19 | Tampering | MCP contract/provenance | mitigate | Assert exact tool/schema/annotations and parse success through public schemas; verify every citation maps to normalized evidence. |
| T-05-20 | Denial of Service | live provider tests | accept | Fixed small fixtures and configured bounds; prerequisites/cost are documented and no unbounded polling is introduced. |
</threat_model>
