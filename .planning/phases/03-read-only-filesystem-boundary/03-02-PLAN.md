<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Policy -> OS filesystem | Only the canonical target returned by successful authorization may be inspected/opened. |
| Descriptor -> Phase 2 normalizer | Bounded bytes and safe logical provenance cross into existing parsers. |
| OS/parser/provider-shaped failures -> response | Untrusted error strings become stable sanitized output; no provider runs in this phase. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-07 | Information Disclosure | read call ordering | mitigate | Authorize before stat/open/read; spy tests assert zero read primitives for denied sources. |
| T-03-08 | Denial of Service | bounded reader | mitigate | Use per-type caps, preflight size, bounded descriptor reads, and final byte-count checks. |
| T-03-09 | Tampering | symlink/TOCTOU target | mitigate | Read canonical target with no-follow/read-only flags where supported, revalidate descriptor, and simulate substitution. |
| T-03-10 | Information Disclosure | error serialization | mitigate | Stable generic codes/messages suppress OS paths, secrets, stacks, and environment values. |
| T-03-11 | Elevation of Privilege | filesystem API | mitigate | Export bounded read/authorize operations only; scan/tests forbid mutation calls. |
| T-03-12 | Repudiation | read result | mitigate | Return root id, normalized relative path, and filesystem URI alongside bytes. |
</threat_model>
