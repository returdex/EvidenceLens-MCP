<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Host project -> container /workspace | Untrusted host files cross into the server through a read-only bind mount. |
| Compose environment/secret source -> provider config | Project-local variables and optional config file select provider credentials/settings. |
| Container runtime -> filesystem/network/kernel | Docker privileges, writable paths, capabilities, and network reachability affect isolation. |
| Image build context -> image layers | Build inputs could accidentally include credentials or unnecessary host state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-06-01 | Information Disclosure | Dockerfile/build context | mitigate | `.dockerignore` excludes `.evidencelens.local.json`, Dockerfile never copies secrets, and config tests grep for credential-bearing copies. |
| T-06-02 | Tampering | `/workspace` evidence mount | mitigate | Compose uses an explicit read-only bind mount and exact `EVIDENCELENS_ALLOWED_ROOTS=course=/workspace`; config tests reject writable mount declarations and require `filesystem://course/...` references. |
| T-06-03 | Elevation of Privilege | container runtime | mitigate | Use non-root image user, `read_only: true`, explicit `/tmp` tmpfs only, and no privileged/extra-capability/host-network/socket settings; inspect the built image and rendered Compose config. |
| T-06-04 | SSRF/Arbitrary Access | provider/network and filesystem | mitigate | Keep direct stdio only, preserve application allowlist, use project-local typed `DEEPSEEK_*` settings, and do not add arbitrary endpoint/module loading or extra mounts. |
| T-06-05 | Information Disclosure | provider startup preflight | mitigate | Docker entrypoint invokes existing config loading before server startup, emits only a stable sanitized configuration message, and exits nonzero for missing key, malformed settings, or env/file conflict; normal local `createServer()` behavior remains unchanged. |
| T-06-06 | Tampering/Misleading Success | deployment declarations | mitigate | Configuration tests require the offline profile’s explicit provider disablement and exact runtime command, preventing a deterministic fallback from being mistaken for real-provider success. |
</threat_model>
