Linux `open(2)` defines `O_NOFOLLOW` for the trailing component of each individual open. Because this reader opens one untrusted component at a time beneath `/proc/self/fd/<opened directory descriptor>`, the flag must be present on every component open. The proc descriptor itself is a trusted symlink and its initial hop must remain followable. References: https://man7.org/linux/man-pages/man2/open.2.html and https://nodejs.org/api/fs.html.
</context>
