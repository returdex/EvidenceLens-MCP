| analyzer observation → finding response | Derived claims and citations cross into the client-visible response. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-06 | Denial of Service | `buildReviewAnalysisInput` | mitigate | Reuse evidence/request caps and bound candidates, token lengths, comparisons, and transient buffers before rule fan-out. |
| T-04-07 | Tampering | citation resolver | mitigate | Resolve only against normalized evidence ids/hashes/typed references and require visual payload/page binding for visual claims. |
| T-04-08 | Information Disclosure | transient analysis data | mitigate | Keep extracted text out of normalized/response schemas; return only bounded summaries, typed citations, hashes, and warnings. |
| T-04-09 | Repudiation | deterministic engine | mitigate | Derive stable ids, normalize/sort claims and citations, use fixed rule order, and test byte-for-byte repeated output. |
| T-04-10 | Elevation of Privilege | analyzer boundary | mitigate | The Phase 4 implementation is provider-independent and has no network, subprocess, write, or direct filesystem access; filesystem data arrives only through Phase 3’s authorized normalization path. |
</threat_model>
